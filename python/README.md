# Python · Students API

A small **FastAPI** service with dummy student and attendance data. FastAPI also
serves interactive docs, which is nice to show in class.

## Endpoints

| Method | Path                  | Description                          |
| ------ | --------------------- | ------------------------------------ |
| GET    | `/`                   | Service info and endpoint list       |
| GET    | `/health`             | `{"status":"ok"}` for checks         |
| GET    | `/api/students`       | `{count, students}`                  |
| GET    | `/api/students/1`     | One student, or `404`                |
| GET    | `/api/attendance`     | `{count, attendance}`                |
| GET    | `/docs`               | Swagger UI generated by FastAPI      |

## Run locally

```bash
cd python
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload
# http://localhost:8000/api/students  ·  http://localhost:8000/docs
```

## Run with Docker

```bash
docker build -t em-net/python-students-api .
docker run --rm -p 5002:8000 em-net/python-students-api
# http://localhost:5002/api/students
```

The image is based on `python:3.12-slim`, installs the two pinned requirements,
and runs Uvicorn as an unprivileged `appuser` on port **8000**.

Suggested tunnel hostname: `python.example.com` → `http://python:8000`.
